Nhúng Tailwind vào file HTML

  1. Mở file HTML trong VS Code và tìm thẻ <head>.
  2. Đặt dòng sau vào trong thẻ đó. Các trang của nhóm đã có sẵn dòng này.
  3. Lưu file, kết nối Internet rồi mở file bằng trình duyệt để dùng Play CDN.
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>

Nhìn thấy khoảng đệm

Đọc khoảng cách từ chữ đến đường viền. Ô thứ hai dùng mức đệm lớn hơn ở cả bốn phía.

Đọc tên class

bg-blue-500
bg là nền, blue là xanh dương, 500 là mức sắc độ.
p-4
p là padding, tức khoảng đệm phía trong. Số 4 là mức trên thang khoảng cách của Tailwind.
rounded-lg
Bo góc phần tử. lg chỉ mức bo lớn.
