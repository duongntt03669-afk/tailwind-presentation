Cách tạo kiểu và tình huống phù hợp
Công cụCách làmKhi nào phù hợp?
CSS thuầnTự đặt tên class và viết từng thuộc tính.Khi muốn tự định nghĩa các quy tắc giao diện.
BootstrapDùng kiểu nút có sẵn rồi tùy chỉnh.Khi cần dựng nhanh bằng các thành phần quen thuộc.
Tailwind CSSGhép class cho nền, chữ và khoảng đệm.Khi muốn chọn từng chi tiết theo thiết kế riêng.

Cùng đọc code

CSS thuần

.nut-xanh { background-color: blue; color: white; }

Bootstrap

class="btn btn-primary"

Hai class chọn mẫu nút chính sau khi đã nhúng Bootstrap.

Tailwind CSS

class="bg-blue-600 text-white"

Hai class lần lượt đặt màu nền và màu chữ.

Vì sao nhóm chọn Tailwind?

Nhóm muốn tự chọn màu nền, khoảng đệm và góc bo của liên kết “Học cách cài đặt”. Mỗi đặc điểm đó có một class riêng, nên khi đổi màu, nhóm vẫn giữ được kích thước nút.
